# إسهام | Esham

منصة لتعلّم ومشاركة المهارات، بواجهات للمتعلّم والمعلّم والحساب الذي يجمع الدورين، إضافة إلى الإدارة العامة وإدارة التصنيفات.

هذا الملف يصف نسخة الفرونت بتاريخ **8 أكتوبر 2026**. التسجيل المحلي للفيديو والتحرير والشهادات يعمل داخل المتصفح؛ بيانات الأعمال الحالية محفوظة على الجهاز. المصادقة والصلاحيات والتخزين المشترك والنشر الفعلي تحتاج خدمات الباك الموضحة أدناه.

## تشغيل المشروع

من مجلد المشروع الذي يحتوي على `package.json`:

```bash
npm install
npm run dev
```

افتح رابط Local الظاهر في التيرمنال؛ قد يكون المنفذ `5173` أو `5174`. يستخدم المشروع React 19 وVite 8؛ يلزم إصدار Node.js متوافق مع Vite 8.

```bash
npm test
npm run build
npm run preview
```

ينفّذ `predev` و`prebuild` السكربت `scripts/video-assets.mjs` تلقائيًا لنسخ خطوط Excalidraw محليًا. لا يلزم رفع `node_modules` أو `dist` أو الخطوط المولّدة إلى Git.

لربط واجهات الحساب بخدمة المصادقة، انسخ `.env.example` إلى `.env.local` وحدّد `VITE_API_BASE_URL` ثم أعد تشغيل Vite. عقود الطلبات في [توثيق الباك](docs/backend-contract.md).

## المكتبات المستخدمة

الإصدارات التالية هي نطاقات الاعتماد المعلنة في `package.json`؛ الإصدارات المثبتة يحددها `package-lock.json`.

| المكتبة | الإصدار المعلن | الاستخدام | الترخيص |
|---|---|---|---|
| React / React DOM | `^19.0.0` | الواجهات والسياقات المشتركة | MIT |
| React Router | `^8.4.0` | التنقل ومسارات الأدوار وتحميل الصفحات عند الحاجة | MIT |
| Vite | `^8.0.0` | التشغيل المحلي وبناء الإنتاج | MIT |
| `@excalidraw/excalidraw` | `^0.18.1` | الوايت بورد: الرسم والنصوص والأشكال والصور والممحاة والتراجع | MIT |
| `wavesurfer.js` | `^8.0.2` | الخط الزمني للفيديو واختيار نطاق القص | BSD-3-Clause |
| `mediabunny` | `^1.61.3` | معالجة الفيديو والقص باستخدام WebCodecs عند توفره | MPL-2.0 |
| `pdfjs-dist` (PDF.js) | `^6.4.299` | عرض صفحات PDF داخل الفيديو | Apache-2.0 |

مكتبات أدوات الفيديو مفتوحة المصدر ولا تتطلب اشتراكًا مدفوعًا أو مفتاح ترخيص للميزات المستخدمة هنا. لا نستخدم Excalidraw Plus أو إضافات ترميز مدفوعة. يجب الحفاظ على إشعارات التراخيص عند توزيع المشروع؛ راجع [تفاصيل التراخيص والمراجع الرسمية](docs/video-tools.md).

التسجيل ومشاركة الشاشة يستخدمان أيضًا واجهات المتصفح الأصلية: `MediaRecorder` و`getUserMedia` و`getDisplayMedia` وCanvas وWeb Audio وIndexedDB. هذه واجهات متصفح وليست مكتبات npm إضافية.

## التعديلات المنجزة

### التنقل واللغة والمظهر

- تنظيم الناف بار بقوائم مجمّعة للحساب وإدارة التعلّم أو التعليم، مع تنظيم العرض على الهاتف.
- دعم العربية والإنجليزية واتجاهي RTL وLTR، والوضع الفاتح والداكن، وحفظ التفضيلات.
- مشاركة الناف والفوتر والسياقات بين صفحات الدور نفسه، وتحميل الصفحات عند الحاجة.
- توحيد بيانات الدورات والتصنيفات والصور بين الرئيسية والكتالوج والتفاصيل وإعداد الحساب وإنشاء الدورة.
- صفحات الدعم وإرشادات المعلّم والخصوصية والشروط، وحالات فارغة ورسائل خطأ واستعادة عند تعطل صفحة. نصوص الخصوصية والشروط أولية للمشروع.

### الحساب والأدوار

- إعداد الحساب: الدور، الملف الشخصي، مجالات التعلّم والتعليم، المهارات والأهداف، ثم ملخص الإكمال.
- البحث بالعربية والإنجليزية في المجالات مع الحفاظ على الاختيارات عند الفلترة.
- تغيير نوع الحساب من الإعدادات إلى متعلّم أو معلّم أو كليهما دون إنشاء حساب جديد.
- الحفاظ على معرّف الحساب وبياناته وسجل التعلّم والتعليم والمحفظة عند تغيير الدور؛ لا يتحول الحساب إلى الدورين تلقائيًا.
- تبديل واجهة التعلّم والتعليم متاح للحساب الذي يجمع الدورين.
- نماذج الدخول والتسجيل واستعادة كلمة المرور وتغييرها وتعديل الحساب وحذفه جاهزة لاستدعاء API عند ضبط عنوان الخدمة، مع حالات التحميل والخطأ. كلمات المرور لا تُحفظ في تخزين المتصفح.

### النقاط والالتحاق

- منح **20 نقطة ترحيبية مرة واحدة لكل حساب** في السجل المحلي؛ لا تُمنح مجددًا مع كل تسجيل دخول أو تغيير دور.
- توحيد تكلفة التسجيل في جميع الدورات إلى **20 نقطة**.
- يحصل صاحب الدورة على **20 نقطة لكل تسجيل متعلّم جديد** فيها.
- منع تكرار الخصم أو المكافأة، والتسجيل في دورة يملكها المستخدم، والتسجيل برصيد غير كافٍ.
- حفظ التسجيل والخصم ومكافأة المعلّم كعملية محلية واحدة؛ فشل الحفظ لا يترك خصمًا جزئيًا.
- توحيد رصيد الناف واللوحات والمحفظة وسجل العمليات. إكمال الدروس أو المهام لا يمنح نقاطًا.

يجب تنفيذ هذه السياسة على الخادم بعمليات ذرية ومنع التكرار قبل الاعتماد عليها بين مستخدمين حقيقيين.

### الدورات والمهام والتقدّم

- استكشاف الدورات والبحث والفلترة والتفاصيل والالتحاق المحلي ومتابعة الدروس وحساب تقدّم الوحدات والدورات.
- حفظ معلومات مسودة الدورة والمنهج والأقسام والدروس والمهام، واستعادتها عند التحديث والرجوع.
- إنشاء وتحرير دروس القراءة والفيديو والموارد، والتحقق من المحتوى قبل اعتبار الدرس جاهزًا.
- الدورة تتطلب من مهمة إلى ثلاث مهام تقييمية إجمالًا؛ لا تُفرض مهمة على كل قسم، وتُمنع إضافة مهمة رابعة.
- مسودات وتسليمات المتعلّم ومرفقاته، ومراجعة المعلّم وطلب التعديل والاعتماد محليًا.
- إرسال الدورة إلى قائمة المراجعة المحلية؛ الموافقة ضمن التصنيف تنشر نسخة معتمدة محلية. التعديل اللاحق لا يغير النسخة المعتمدة حتى اعتماد التعديلات.
- تقييمات وردود وتوصيات بعد الإكمال؛ التوصيات الحالية قواعد محلية موضحة للمستخدم، وليست استجابة خدمة ذكاء اصطناعي.

### الشهادات

- نقل الوصول إلى «شهاداتي» إلى صفحات الدورات للمتعلّم والمعلّم لتخفيف الناف بار.
- معاينة الشهادة بعد إكمال الدروس واعتماد المهام المطلوبة.
- عرض وحفظ الشهادة بالعربية أو الإنجليزية، مع إمكانية تحديد كتابة الاسم بالإنجليزية.
- تنسيق رسمي مناسب للشركات باستخدام Arial/Tahoma، وحفظ PDF وطباعة على **صفحة A4 أفقية واحدة**.
- الشهادة الحالية معاينة؛ تاريخ الإصدار ومعرّف التحقق والاعتماد الرسمي واستحقاق الخادم تحتاج الباك.

### إنشاء الفيديو وتحريره

- تسجيل فيديو فعلي داخل المتصفح وحفظه محليًا ومعاينته وربطه بالدرس، إضافة إلى استيراد ملف فيديو.
- تسجيل الكاميرا والميكروفون أو الشاشة، ودمج الشاشة مع الكاميرا والوايت بورد والعرض في فيديو واحد بدقة `1280×720`.
- مشاركة الشاشة مع استمرار الكتابة والرسم، ووضع الوايت بورد بجانب شاشة العرض الثابتة؛ تحت عرض 700px تظهر المعاينة فوق اللوحة أثناء التمرير.
- أدوات الرسم والنص والأشكال والأسهم والصور والممحاة والتراجع والإعادة وقلم التظليل، وحفظ المشهد لكل درس.
- عرض التعليقات بخلفية شفافة فوق الشاشة المشتركة، مع خيار إظهارها داخل الفيديو.
- مزامنة حذف الرسم فورًا مع المعاينة واستبعاد العناصر المحذوفة من التصدير.
- عرض مستوى الصوت الفعلي للميكروفون، وخيارات الأجهزة والكاميرا والميكروفون، ورسائل للأذونات والأجهزة والتخزين.
- إصلاح التسجيل الفارغ للمحتوى الثابت بطلب إطارات Canvas صراحةً منذ أول إطار. يبدأ الصوت فقط عند وجود مسار صوت حي، وتبقى مشاركة الشاشة متاحة لإعادة المحاولة إذا فشل بدء التسجيل.
- تشغيل الفيديو وخط زمني وتحديد بداية ونهاية القص وإنتاج ملف مقصوص فعليًا. الملفات الكبيرة أو الصوت غير القابل للفك تستخدم خطًا زمنيًا بالوقت دون الموجة الصوتية.
- استخدام WebCodecs للقص عند الدعم، مع مسار بديل يعتمد Canvas وMediaRecorder، وتسوية الصوت باستخدام Web Audio.
- عرض PDF والصور داخل الفيديو؛ يمكن حفظ ملفات Word وPowerPoint كمرفقات، أما عرضها مباشرةً فيحتاج خدمة تحويل. يمكن مشاركة شاشة عرضها حاليًا.

تفاصيل الأدوات واختبارات الفيديو في [docs/video-tools.md](docs/video-tools.md).

### الإدارة والإبلاغ

- قائمة أدمن مؤقتة في وضع التطوير للوصول إلى الإدارة العامة `/admin` وإدارة التصنيف `/category-admin`؛ لا تظهر في بناء الإنتاج.
- إدارة معاينة المديرين والتصنيفات والإعلانات والبحث وسجل النشاط، ومراجعة الدورات بحسب التصنيف.
- إرسال بلاغ عن دورة أو درس مع سبب ووصف وتوقيت، ومنع البلاغ المفتوح المكرر، ومتابعته في طابور الإدارة المحلي.
- التحقيق وتسجيل النتيجة وإغلاق البلاغ أو رفضه؛ البلاغ أو التقييم لا يصدر إنذارًا تلقائيًا.
- إنذارات محلية تتطلب دليلًا ومعرّف حادثة وسببًا وتصحيحًا وموعدًا؛ الإنذار الثاني يوقف التسجيل في الحالة المحلية والثالث يؤرشف مع حفظ السجل، مع واجهات الاستئناف والإيقاف العاجل.
- الإشعارات وحالة قراءتها مشتركة بين الجرس وصفحة الإشعارات بحسب الدور.

روابط الأدمن المؤقتة وضوابط الواجهة ليست صلاحيات أمنية؛ يلزم فرض الصلاحيات على الخادم.

## التحقق وحدود الدعم

- **34 اختبارًا آليًا** عبر `npm test`: النقاط والأدوار وحفظ المسودات والنشر والتسليمات ونطاق الإدارة والشهادات والبلاغات والتحقق من الملفات وطلبات الحساب وعرض الصفحات باللغتين.
- بناء الإنتاج عبر `npm run build` ناجح. قد تظهر تحذيرات تبعيات أثناء التثبيت أو البناء؛ نجاح البناء لا يثبت دعم جميع الأجهزة.
- فحوص متصفح محددة للتنقل والعربية والإنجليزية وأحجام الهاتف، ومعاينات PDF للشهادات على صفحة واحدة.
- تسجيل Canvas فعلي لمدة 4.171 ثانية وقصه إلى ثانيتين وحفظه؛ تصدير رسم Excalidraw وعرض صفحة PDF في إطار الفيديو.
- فحص واجهة التسجيل الفعلية: حفظ فيديو WebM لمدة 7.7 ثانية بدقة `1280×720` وحجم نحو 91KB والوصول إلى المعاينة؛ حذف رسم وإزالته من اللوحة والمعاينة معًا.

صفحات الفحص المحلية: `/tests/media-preview.html` و`/tests/video-tools.html` و`/tests/recording-preview.html` و`/tests/points-preview.html`. تُستخدم في التطوير ولا تدخل ضمن مداخل بناء الإنتاج.

اختيار الشاشة من نافذة النظام والكاميرا والميكروفون الفعليان يحتاجان اختبارًا يدويًا على الأجهزة المستهدفة. مشاركة الشاشة تحتاج HTTPS أو localhost وموافقة المستخدم ودعم `getDisplayMedia`. دعم صوت النظام والترميزات وWebCodecs يختلف بحسب المتصفح والنظام، ولا يُفترض توفر مشاركة الشاشة على الموبايل. لا تعني نتائج الفحص أن كل حالة ممكنة قد اختُبرت.

## المتبقي للباك والإنتاج

- مصادقة فعلية وجلسات آمنة واستعادة الجلسة وصلاحيات الأدوار والإدارة.
- تخزين مشترك للحسابات والدورات والمنهج والتقدّم والمهام والبلاغات والإشعارات.
- سجل نقاط موثوق يطبق المنحة والخصم ومكافأة المعلّم ذريًا ويمنع التكرار.
- رفع وتنزيل الملفات بروابط مصرح بها وتخزين الفيديو ومزامنته بين الأجهزة.
- نشر ومراجعة الدورات وفرض الإيقاف والأرشفة على التسجيل من جهة الخادم.
- إصدار الشهادات والتحقق منها والبريد واستعادة كلمة المرور عبر خدمة حقيقية.
- ربط المساعد وفحص المحتوى والتوصيات بخدمات الذكاء الاصطناعي؛ الواجهات الحالية لا تثبت حدوث تحليل آلي.

راجع [عقود الباك](docs/backend-contract.md) و[توثيق الفيديو](docs/video-tools.md) قبل الربط. صفحات الفرونت والتخزين المحلي ليست بديلًا عن هذه الخدمات.

## GitHub

لتنزيل المشروع لأول مرة:

```bash
git clone https://github.com/skillifyproj-creator/esham.git
cd esham
npm install
npm run dev
```

لسحب تحديثات الفرع الحالي بعد حفظ عملك:

```bash
git pull origin master
npm install
```

لرفع تغييرات الكود والتوثيق من النسخة المحلية الحالية دون ملفات الفحص المولّدة داخل `artifacts` و`output`:

```bash
git status
git add README.md docs src scripts tests package.json package-lock.json .gitignore .env.example
git commit -m "Document frontend features and fix video recording and whiteboard sync"
git push origin master
```

هذه الأوامر لا ترفع ملفات `.env.local` أو كلمات المرور. راجع `git status` قبل إنشاء الالتزام، ولا تستخدم `--force` لتجاوز اختلاف الفرع البعيد.
