# إسهام — بيانات كورسات موحّدة

## التشغيل

افتحي المجلد الذي يحتوي package.json في VS Code، ثم:

```bash
npm install
npm run dev
```

## التعديل على الكورسات

المصدر الوحيد هو `src/data/courses.js`.
كل سجل يحتوي الصورة والعنوان والوصف بالعربية والإنجليزية والفئة والنقاط والتقييم والمدرّب والكلمات المفتاحية والمنهج والنتائج التعليمية.
الرئيسية والاستكشاف والتفاصيل تقرأ نفس القائمة، ولا توجد قائمة ثانية في catalog.js.
غيّري `image` مرة واحدة لتتغير الصورة في كل الصفحات. صورك الأصلية محفوظة بنفس الأسماء.
عدد الدروس يُحسب من curriculum؛ أضيفي الدرس هناك بدل تعديل عدد مستقل.
لإضافة دورة، انسخي سجلًا داخل courseRecords، أعطيه id فريدًا، وعدّلي حقوله. لا يعتمد النص على ترتيب السجل أو id متسلسل. أبقي category ضمن categoryKeys والفئة من الفئات الموجودة.
`courseHelpers.js` أدوات لقراءة النصوص والمنهج حسب اللغة فقط، ولا يحتوي بيانات كورسات أخرى.
ملفات i18n تحتوي نصوص الواجهة، أما النصوص الخاصة بالكورس فهي داخل سجله.

## الربط

- `/`: الرئيسية.
- `/courses`: الاستكشاف.
- `/courses/:courseId`: تفاصيل نفس الدورة.
- الهيدر وزر اكتشف الدورات والتذييل يفتحون الاستكشاف.

## تطبيق التعديل على مشروعك الحالي

يمكن تشغيل هذه النسخة كاملة. أو احتفظي بنسخة احتياطية ثم انسخي src من هذه النسخة إلى مشروعك بدمج الملفات، واحذفي الملف القديم `src/data/catalog.js` إذا بقي عندك. لا تستبدلي بيانات Git المحلية. لم نغيّر صورك أو ثيماتك أو اسم المنصة.
الملفات المعدلة: courses.js، courseHelpers.js، HomePage.jsx، CoursesPage.jsx، CourseDetailsPage.jsx، CourseCard.jsx، translations.js، coursePagesCopy.js.

الحسابات والتقييمات والمنهج والاشتراك ما زالت بيانات/محاكاة فرونت تجريبية حتى ربط الباك. عند النشر، إعداد SPA مطلوب لفتح روابط التفاصيل مباشرة.
