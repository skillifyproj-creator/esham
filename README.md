# إسهام — الصفحة الرئيسية

واجهة React + Vite بالعربية والإنجليزية، مع Light / Dark Mode وتصميم متجاوب.
الصفحة مستوحاة من التصميم المرفق، وليست مطابقة حرفية للبكسلات أو لكل النصوص الصغيرة.

## 1. المتطلبات

- VS Code.
- Node.js بإصدار 22.12 أو أحدث (أو 20.19 فأحدث من سلسلة 20).
- npm يأتي مع Node.js.

للتحقق داخل Terminal:

```bash
node -v
npm -v
```

## 2. تشغيل المشروع الجاهز

1. فكّي ضغط `esham-frontend.zip`.
2. افتحي مجلد `esham-frontend` في VS Code: File → Open Folder.
3. افتحي Terminal → New Terminal، وتأكدي أنه داخل المجلد الذي يحتوي `package.json`.
4. نفّذي:

```bash
npm install
npm run dev
```

افتحي الرابط الذي يظهر في التيرمنال؛ غالبًا `http://localhost:5173`.
لإيقاف السيرفر استخدمي `Ctrl + C`.

لإنشاء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## 3. المكتبات

- `react`: المكونات وحالة الواجهة.
- `react-dom`: عرض React داخل الصفحة.
- `vite`: تشغيل المشروع وتجهيز نسخة الإنتاج.

الأمر `npm install` ينزّل كل هذه المكتبات من `package.json`.
الأيقونات SVG محلية؛ لا تحتاج تثبيت مكتبة أيقونات.
CSS عادي؛ لا تحتاج Tailwind أو Bootstrap أو Sass.
لم نضف Router أو Axios لأن هذه المرحلة صفحة واحدة دون API؛ يمكن إضافتهما عند الحاجة.
الخطوط من Google Fonts؛ تحتاج اتصالًا بالإنترنت. توجد خطوط احتياطية إذا تعذّر تحميلها.

## 4. مسارات الملفات ووظائفها

كل المسارات التالية بالنسبة لمجلد المشروع `esham-frontend/`:

| المسار | الوظيفة |
| --- | --- |
| `index.html` | نقطة دخول HTML، اللغة والاتجاه الأساسيان |
| `package.json` | المكتبات وأوامر التشغيل |
| `package-lock.json` | إصدارات المكتبات المثبتة |
| `src/main.jsx` | تشغيل React واستيراد CSS العام |
| `src/App.jsx` | الصفحة الرئيسية وموفر الإعدادات |
| `src/pages/HomePage.jsx` | ترتيب أقسام الصفحة والتفاعلات |
| `src/components/Header.jsx` | الهيدر والتنقل واللغة والثيم |
| `src/components/CourseCard.jsx` | بطاقة دورة قابلة لإعادة الاستخدام |
| `src/components/Modal.jsx` | نافذة تفاصيل الدورة والاختبار والتنبيهات |
| `src/components/Icon.jsx` | أيقونات SVG |
| `src/context/PreferencesContext.jsx` | إدارة اللغة والثيم وحفظهما |
| `src/i18n/translations.js` | النصوص العربية والإنجليزية |
| `src/data/courses.js` | بيانات الدورات التجريبية بمعرّفات ثابتة |
| `src/styles/global.css` | نظام التصميم المشترك وتنسيق الصفحة |
| `public/images/hero.webp` | صورة المقدمة |
| `public/images/design.webp` | صورة دورة التصميم |
| `public/images/embroidery.webp` | صورة دورة التطريز |
| `DESIGN_SYSTEM.md` | مرجع الخطوط والألوان للصفحات القادمة |

لا يوجد `vite.config.js` لأن إعدادات Vite الافتراضية تكفي هنا.

## 5. إذا عندك مشروع React + Vite بالفعل

- احتفظي بنسخة من ملفات مشروعك قبل الاستبدال.
- انسخي `src/` و`public/images/` إلى مشروعك.
- استبدلي `index.html` أو انقلي منه إعدادات اللغة والاتجاه ووسم viewport ونقطة دخول main.jsx.
- إذا عندك صفحات موجودة، ادمجي `HomePage` بدل استبدال `App` بالكامل، وضعي `PreferencesProvider` حول التطبيق.
- لا تستبدلي `package.json` أو `package-lock.json` لمشروع أكبر دون مراجعة مكتباته.

إذا تفضّلي إنشاء الهيكل بنفسك بدل استخدام الملف الجاهز:

```bash
npm create vite@latest esham-frontend -- --template react
cd esham-frontend
npm install
```

ثم انسخي ملفات الكود من المشروع الجاهز إلى نفس مساراتها وشغّلي `npm run dev`.
احذفي أو أوقفي استيراد تنسيق القالب الافتراضي مثل `App.css` حتى لا يتعارض مع التصميم.

## 6. التفاعلات الحالية

- العربية RTL، والإنجليزية LTR، وترجمة الأقسام والبطاقات والنوافذ.
- تبديل اللايت والدارك مع حفظ الاختيارات في `localStorage`.
- قائمة تنقل قابلة للفتح والإغلاق على الموبايل.
- فلترة الدورات حسب المجال، دون فقد الفلتر عند تغيير اللغة.
- نافذة تفاصيل الدورة، ويمكن إغلاقها بـ Escape.
- اختبار مبسط حسب اهتمام واحد يقود للدورات المناسبة.

**حدود هذه المرحلة:** أرقام المجتمع والدورات بيانات تجريبية. أزرار إنشاء الحساب وتسجيل الدخول تعرض تنبيهًا توضيحيًا؛ لا تنشئ حسابًا. لا يوجد تسجيل فعلي للدورات أو باك أو نظام نقاط حتى الآن.

## 7. تغيير النصوص والصور

- غيّري النصوص داخل `src/i18n/translations.js` في اللغتين.
- الفئات لها مفاتيح ثابتة داخل `categoryKeys`؛ ترجمتها لا تغيّر بيانات الفلترة.
- صور المرجع مقصوصة من الصورة المرفقة، لذلك جودتها محدودة. استبدليها بصور أصلية عالية الجودة بنفس الأسماء في `public/images/` عندما تتوفر.
- إذا غيّرتِ أسماء الصور، غيّري المسارات في `HomePage.jsx` أو `courses.js`.

## 8. عند ربط الباك لاحقًا

1. حدّدي شكل استجابة API للدورات والحسابات.
2. استبدلي مصدر الدورات التجريبي بطلب API مع حالات تحميل وخطأ وبيانات فارغة.
3. احتفظي بـ `id` ومفاتيح الفئات ثابتة؛ اجعلي اسم الدورة ووصفها يدعمان اللغتين.
4. أنشئي صفحات Login وRegister وارْبطي الأزرار بها.
5. اعتمدي المصادقة والنقاط والتسجيل بالدورات من السيرفر.
6. لا تضعي مفاتيح سرية في كود الفرونت؛ أي متغير يبدأ بـ `VITE_` يصل للمتصفح.

## 9. صفحات المستقبل

راجعي `DESIGN_SYSTEM.md`. استخدمي نفس `Header` و`PreferencesProvider` ونفس متغيرات CSS. ضعي نصوص أي صفحة جديدة داخل ملف الترجمات في اللغتين. لا تثبتي `direction: rtl` على العناصر لأن الاتجاه يأتي من `html` ويتغير مع اللغة.
