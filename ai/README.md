# خدمة مراجعة الفيديو المستقلة

## الشات بوت والتوصيات — إضافة 24 أكتوبر 2026

الشات مساعد محادثة عام: يشرح ويكتب ويترجم ويساعد بالبرمجة من معرفة النموذج، ولا يتقيد بكتالوج Coursera. بيانات الدورات ومعرفة إسهام تُستخدم عندما يتعلق السؤال بالمنصة أو توصياتها. الإجابة العامة لا تُرفق بمراجع مختلقة، والواجهة لا تعرض اسم المزوّد أو عبارة تنسب الإجابة إليه. لا يوجد بحث ويب حي، فلا يدّعي المساعد أنه بحث أو تحقق من معلومات آنية.

المزوّد الحالي للشات تحدده `CHAT_PROVIDER` داخل ملف الأسرار المحلي. الافتراضي `google` ليعمل بالمفتاح المضبوط أصلًا. لا يتغير فحص الفيديو بتغيير مزوّد الشات.

لدعم DeepSeek ضع القيم التالية في `ai/.env` محليًا، ثم أعد تشغيل خدمة المساعد فقط:

```dotenv
CHAT_PROVIDER=deepseek
DEEPSEEK_API_KEY=your_private_key
DEEPSEEK_MODEL=deepseek-flash
```

مفتاح Google لا يعمل لدى DeepSeek. المفتاحان لا يظهران في الفرونت، ولا يُرسل مفتاح إلى المزوّد الآخر. لا يحدث تبديل تلقائي لمزوّد آخر عند الفشل؛ تعود رسالة تعذّر واضحة. تكامل DeepSeek اختُبر بردود محاكية لواجهة Chat Completions وJSON Output؛ لم يُنفّذ طلب حقيقي إليه لعدم ضبط مفتاحه. التشغيل الفعلي بالمفتاح الحالي اختُبر على الخدمة الحالية.

المراجع: [DeepSeek API](https://api-docs.deepseek.com/)، [JSON Output](https://api-docs.deepseek.com/guides/json_mode/). أسماء النماذج ومتغيرات الأسرار تفاصيل إعداد داخلية وليست أسماء ظاهرة للمستخدم.

أُضيفت خدمة تعلم مستقلة على `127.0.0.1:8001`، منفصلة عن خدمة الفيديو على 8000 وعن الباك القائم. ملفات `backend/` لم تتغير. تستعمل المفتاح نفسه من `.env`؛ لا تحتاج مفاتيح في الفرونت.

```powershell
npm --prefix ai run data:prepare
npm --prefix ai run assistant
```

ثم افتح `/assistant` من الواجهة المحلية. `POST /chat` يبحث في معرفة إسهام والكتالوج المتاح والدورات الخارجية ثم يرسل السؤال والمراجع وسياق ست رسائل كحد أقصى للنموذج؛ يعيد جوابًا مع مصادر تتحقق الخدمة من معرفاتها وتبني روابطها من السجلات المعروفة. لا تُرسل هوية الحساب أو رصيده أو بيانات دخوله للنموذج. يدعم المساعد تحليل النص المستخرج من PDF/TXT وتحليل نسخة مصغرة من الصور؛ لا يحفظ ملفات المرفقات على الخادم. الحدود وتوزيع الخدمات موثقة في DEPLOYMENT.md.

`POST /recommendations` يرتب المحتوى بـTF–IDF، بتوسيع مصطلحات عربية/إنجليزية وتفضيل مهارات صريحة، دون استدعاء نموذج خارجي. النطاق `platform` يقترح فقط معرفات من كتالوج الواجهة ويستبعد المسجل بها والمستكملة والمسودات؛ والنطاق `external` يعيد مراجع Coursera منفصلة لا تسجّل بنقاط إسهام. اقتراحات ما بعد الدورة تستخدم اهتمامات الحساب المحلية وملاحظاته، مع رجوع واضح لمقترحات المجال المحلية عند غياب الخدمة. ليست البيانات المحلية إثباتًا لخادم الحسابات.

المصدر والتنظيف والاستكمال موثقة في [دليل البيانات](data/README.md). لا يُدرّب نموذج محادثة جديد؛ التنفيذ بحث مستندات مع نموذج جاهز للإجابة، وليس تدريب LLM على ملفات CSV. القيم التقديرية موسومة ولا تُستخدم كحقائق في إجابات الشات.

الخدمة للتطوير المحلي فقط: Host وOrigin على loopback، جسم JSON حتى4MiB، 15طلبًا بالدقيقة وطلبان متزامنان، ومهلة90ثانية. لا تُسجّل الأسئلة أو الأسرار ولا تُحفظ جلسات على الخادم. لا تعرّض المنفذ على الإنترنت. النشر وربط الأرصدة والتسجيلات الحقيقية يحتاجان لاحقًا تكاملًا مفوضًا مع خدمة الحسابات؛ لا توجد هوية موثقة أو صلاحيات تنفيذ أعمال في هذه الخدمة.

اختبارات إضافية:

```powershell
npm --prefix ai test
python -m unittest discover -s ai/tests -p test_*.py
```

استعمل `GEMINI_CHAT_MODEL` لتحديد نموذج نصي متاح لحسابك؛ الافتراضي للشات حاليًا `gemini-3.5-flash-lite`. مجرد ظهور نموذج في قائمة Google لا يضمن إتاحته لحساب جديد، لذلك نختبر الاستدعاء الفعلي ولا نخفي فشله برد جاهز يوهم المستخدم بنجاح AI.

---

خدمة Node.js محلية لـGoogle Gemini داخل ai/؛ لا تعدّل ملفات backend/ أو بياناته أو تسجيل الدخول. واجهة الفيديو تستخدم خدمة المراجعة وحدها، دون عرض اسم النموذج أو اختيار طريقة الفحص. لا توجد اعتمادات npm إضافية؛ نستخدم HTTP وfetch المدمجين في Node 22.12 أو أحدث.

## التشغيل

من جذر المشروع، إذا لم يكن ai/.env موجودًا:

```powershell
Copy-Item ai/.env.example ai/.env
notepad ai/.env
```

ضع المفتاح في GEMINI_API_KEY داخل الملف محليًا. لا تشاركه بالشات أو Git، ولا تضعه في VITE_* أو ملفات الفرونت. اضبط GEMINI_MODEL إذا احتجت نموذجًا آخر يدعم الفيديو وStructured Outputs ومتاحًا لحسابك.

```powershell
npm --prefix ai start
npm run dev -- --host 127.0.0.1 --port 5174
```

شغّل الأمرين في تيرمنالين منفصلين. في معاينة الفيديو اضغط زر الفحص. يوضح الهوفر أن الفيديو والصوت المتاح يُرسلان إلى Google؛ لا توجد قائمة مزود أو مربع موافقة منفصل، حسب تصميم الواجهة المطلوب. لا يوجد تحويل إلى فحص محلي عند فشل الخدمة. الحفظ يفحص النسخة المعدلة من جديد إن لزم، ويوقف حفظ الدرس إذا ظهرت نتيجة تحتاج مراجعة.

## حدود هذه النسخة

- خدمة تطوير تستمع على 127.0.0.1:8000 فقط؛ تقبل أصول localhost المحددة في ALLOWED_ORIGINS وتتحقق من Host وOrigin والموافقة.
- الاتصال بالخدمة المستقلة متاح في وضع Vite التطويري فقط؛ في الإنتاج لا تُعتمد نتيجة عند غياب الخدمة. لا تعرّض الخدمة أو مفتاحها للإنترنت أو تستخدم نفقًا كبديل لتوثيق المستخدم. نشرها يحتاج لاحقًا تنسيقًا مع الباك لتوثيق المستخدم وملكية الفيديو والحصص وتخزين قرار المراجعة؛ هذا الربط غير منفذ.
- MP4 أو WebM حتى 20MiB و600 ثانية، طلب متزامن واحد وخمسة طلبات بالدقيقة ومهلة تحليل دقيقتين. هذه حدود تنفيذنا وليست حدود Google العامة.
- GET /health يبيّن وجود المفتاح فقط؛ لا يختبر صلاحيته. POST /video/review يستقبل بايتات الفيديو والرؤوس X-Media-Id وX-Video-Duration وX-Review-Consent.
- إرسال inline إلى Google عبر HTTPS. لا نحفظ الفيديو على قرص خدمة AI ولا نسجّل المفتاح أو الرد الخام، وتبقى سياسات Google لمعالجة البيانات مطبقة. قد يُحتسب استخدام على مشروع Google؛ لا توجد عملية شراء أو تفعيل فوترة هنا.
- التقرير يحتوي توقيت المشهد وتصنيفه وسببًا بالعربية والإنجليزية، ولا يعرض نسب ثقة مصطنعة. نتحقق من بنية الرد ونربطه بمعرف الملف ومدته.
- حجب Google للطلب بسبب السلامة أو نتيجة غير مؤكدة يؤدي إلى review؛ الرد غير الصالح أو المقطوع أو المفتاح المفقود أو نفاد الحصة يؤدي إلى خطأ، ولا يعتمد الفيديو.
- no-flags نتيجة إرشادية وليست شهادة ملاءمة للأطفال أو موافقة نشر. النموذج قد يفوّت مشاهد، ولا تعني مراجعة الفيديو فحص كل إطار أو فهم الصوت بدقة مضمونة. يلزم تقييم على أمثلة مصنفة ومراجعة بشرية.
- لا يوجد حذف تلقائي أو قاعدة بيانات أو قرار إداري نهائي في هذه الخدمة. الفحص الحالي يبقى جزءًا من تدفق الفرونت المحلي.

### تبويبات المحادثة ومعرفة الموقع

تبويبات المحادثة وسجل الجلسات والمصادر تعمل بالعربية والإنجليزية وعلى الهاتف. السجل يحفظ آخر 20 محادثة، حتى 100 رسالة لكل محادثة، في `sessionStorage` للتبويب حسب هوية الحساب المحلية؛ يمكن فتح المحادثة أو حذفها. تبقى المحادثات بعد تحديث الصفحة، ولا تتزامن بين الأجهزة ولا تبقى بعد انتهاء جلسة التبويب. لا تُحفظ ملفات المرفقات أو روابط blob أو تفاصيل الأخطاء، وتُتحقق روابط المصادر عند الاستعادة. فشل التخزين يظهر رسالة مع إبقاء المحادثة متاحة بالذاكرة. المصادر تجمع مراجع المحادثة المفتوحة دون تكرار.

معرفة الموقع في `src/knowledge.mjs` تشمل بدء الاستخدام والتنقل والأدوار والنقاط والتسجيل والدروس والمهام والشهادات وإنشاء الفيديو والسلامة. تُرسل المعرفة الصغيرة كاملة مع المراجع المسترجعة حتى لا تفقد الأسئلة المختلطة سياق السياسات. لا يمنح ذلك وصولًا لبيانات الحساب الخاصة أو القدرة على تنفيذ عمليات. بعد تغيير المعرفة أو تعليمات النموذج أعد تشغيل خدمة المساعد.

### تحديث تجهيز النشر والمرفقات والزوار

راجع [دليل النشر والتسليم](DEPLOYMENT.md) للبوابة التي تعيد استخدام جلسة الحساب الحالية دون تعديل الباك. الزوار يستطيعون السؤال عن إسهام دون حساب، بإجابات المعرفة المملوكة للمشروع؛ المحادثة العامة والمرفقات تحتاجان جلسة موثقة في البوابة. أصبحت عناوين خدمات الفرونت قابلة للضبط للنشر دون مفاتيح في حزمة المتصفح. تمت إضافة PDF/TXT وتحليل الصور، وفحوصات تقييم قابلة للإعادة، وصورة Docker مع مصدر بيانات مثبت بالبصمة. تشغيل الحاوية والنطاق المنشور يحتاجان استضافة وإعدادات فعلية؛ ليسا نشرًا تم إنجازه. قائمة قاعدة البيانات موجودة في نهاية دليل النشر وREADME الجذري.
