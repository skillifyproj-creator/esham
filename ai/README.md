# AI — خدمة المستقبل

مجلد مستقل للتطوير الجديد؛ لا توجد خدمة AI على الخادم منفذة أو حزمة نماذج مثبتة هنا. تجربة CLIP الحالية تعمل في `frontend/src/services/videoScreening.js` ومتعلقة بالمتصفح؛ بقيت هناك دون تغيير.

| المسار | المسؤولية |
|---|---|
| `src` | نقاط خدمة الاستدلال واستخراج لقطات/صوت ومعالجة النتائج |
| `models` | ذاكرة النماذج المحلية؛ الأوزان لا تُرفع إلى Git |
| `tests` | اختبارات الخدمة وتقييم الدقة والأخطاء على بيانات مرخصة |

بعد تحديد التقنية أضف ملف الاعتمادات المناسب وانسخ `.env.example` إلى `.env`. استدعاءات هذه الخدمة تمر عبر الباك، الذي يتحقق من المستخدم والمحتوى ويقرر النشر أو المراجعة. نتيجة النموذج لا تمنح صلاحية ولا تعني تلقائيًا أن الفيديو آمن للأطفال.

راجع [حدود فحص الفيديو الحالي](../docs/local-video-screening.md) و[تقسيم المشروع](../docs/architecture.md). لا تضف فيديوهات المستخدمين أو أوزانًا كبيرة أو مفاتيح خدمات إلى المستودع.
