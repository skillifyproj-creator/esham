# تنظيم مشروع إسهام — 13 أكتوبر 2026

## الحدود الحالية

- `frontend/`: تطبيق React/Vite الحالي كاملًا، بما فيه الاختبارات والتسجيل والقص وفحص CLIP المحلي. كل المسارات الداخلية بين الملفات بقيت كما كانت.
- `backend/`: هيكل API وقاعدة البيانات وقواعد الأعمال للعمل الجديد؛ لا يوجد تنفيذ خادم بعد.
- `ai/`: هيكل خدمة AI مستقبلية؛ لا يوجد تنفيذ خدمة بعد.
- `docs/`: عقود الربط والتوثيق الذي يحتاجه الفريق كله.

## تدفق الربط المستقبلي

```text
المتصفح (frontend) → API والجلسة والصلاحيات (backend) → قاعدة البيانات / تخزين الملفات
                                             └→ خدمة AI → نتيجة تحليل → مراجعة/قرار على الباك
```

الباك يملك الأدوار والمصادقة والنقاط والنشر والاستحقاق. AI يعطي نتائج للاستدلال، والفرونت يعرض حالات التحميل والأخطاء والنتائج؛ لا يعتمد الخادم على قرارات المتصفح وحدها.

## التشغيل والاعتمادات

ملف npm الجذر خاص بأوامر الفريق؛ لا يحوي مكتبات التطبيق. `frontend/package.json` و`frontend/package-lock.json` يملكان اعتماداته المستقلة. تثبيت الجذر يستدعي `npm ci --include=dev` في الفرونت، ثم أوامر `dev/build/preview/test` تحيل التنفيذ إلى مجلده.

عند بدء الباك وAI، أضف ملفات الاعتمادات والاختبارات لكل خدمة وأوامر تشغيلها إلى الجذر بحسب التقنية المختارة. لا يوجد حاليًا أمر يوهم بتشغيل باك أو AI غير منفذين.

## ما تغيّر بالنقل

- انتقلت `src/public/scripts/tests/index.html` وملفات npm والبيئة للفرونت إلى `frontend/`.
- بقيت روابط الموقع مثل `/courses` و`/learner` و`/admin` دون تغيير؛ جذره عند Vite هو `frontend/`.
- بقيت صفحات فحص المتصفح في `/tests/...` عند التشغيل التطويري؛ لا تدخل بناء الإنتاج.
- انتقال الملفات لا يغير التخزين المحلي، لكن تغيير النطاق أو المنفذ يغير أصل التخزين؛ حافظ على عنوانك السابق عند التحقق.
- Netlify وVercel يبنيان من جذر المستودع وينشران `frontend/dist`؛ ملف Netlify لإعادة التوجيه يُنسخ من `frontend/public/_redirects`.
- `frontend/.env.production` ما زال يفعّل معاينة الأدمن لنسخة العرض؛ الأسرار الجديدة تخص مجلد الخدمة ولا توضع في الفرونت.

## بدء الربط

1. اعتماد التقنية وقاعدة البيانات وعقد الاستجابات في `docs/backend-contract.md`.
2. تنفيذ الجلسات والهوية والأدوار ثم سجل النقاط والتسجيل الذري.
3. ربط رفع الملفات والمنهج والتسليمات والمراجعة والنشر بخدمات مشتركة.
4. إضافة طابور فحص فيديو وخدمة AI، وتقييمها قبل فرض أحكام تلقائية.
5. توفير اختبارات تكامل واستعادة جلسة وصلاحيات ومراجعة بشرية ونشر مستقل لكل خدمة.
