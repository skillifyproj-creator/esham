# Backend — هيكل البداية

هذا المجلد جاهز للعمل الجديد؛ لا يحتوي خادمًا أو مصادقة أو قاعدة بيانات منفذة. لم يُحدد إطار عمل أو لغة بعد.

| المسار | المسؤولية |
|---|---|
| `src/config` | قراءة الإعدادات والتحقق منها واتصال الخدمات |
| `src/modules/auth` | الدخول والخروج والجلسات واستعادة كلمة المرور |
| `src/modules/users` | الهوية والملف والأدوار مع الحفاظ على السجل |
| `src/modules/courses` | الدورات والمنهج والمراجعة والنشر |
| `src/modules/enrollments` | التسجيل والوصول إلى المحتوى |
| `src/modules/points` | السجل المالي للنقاط والعمليات الذرية ومنع التكرار |
| `src/modules/media` | رفع وتنزيل الملفات وروابط التخزين المصرح بها |
| `src/modules/moderation` | البلاغات وفحص المحتوى والمراجعة البشرية |
| `src/modules/certificates` | الاستحقاق وإصدار الشهادات والتحقق منها |
| `src/modules/notifications` | الإشعارات وتسليمها |
| `src/middleware` | التحقق من الجلسة والصلاحيات ومعالجة الأخطاء |
| `src/integrations` | ربط AI والتخزين والبريد |
| `src/jobs` | المهام الطويلة والخلفية، ومنها فحص الفيديو |
| `database/migrations` | تغييرات مخطط قاعدة البيانات |
| `tests` | اختبارات API والصلاحيات وقواعد الأعمال |

ابدأ بتحديد التقنية وإضافة ملف الاعتمادات المناسب، ثم انسخ `.env.example` إلى `.env`. لا تنشئ بيانات دخول أو نقاط وهمية كبديل عن الخدمات.

العقود المطلوبة في [عقود الباك](../docs/backend-contract.md)، وتقسيم المسؤوليات في [التصميم المعماري](../docs/architecture.md). استدعاء خدمة AI يكون من الباك، وقرار النشر والصلاحيات يبقيان عنده.
