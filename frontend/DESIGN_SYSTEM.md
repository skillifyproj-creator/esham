# نظام تصميم إسهام

هذا المرجع والكود هما نقطة البداية المشتركة للصفحات القادمة.

## الهوية

ألوان مستوحاة من الصورة: بني خمري، أخضر هادئ، وردي ترابي، وأبيض مع كريمي.

| الرمز | لايت | دارك | الاستخدام |
| --- | --- | --- | --- |
| `--text` | `#1C1C17` | `#F8F1F2` | النص الرئيسي |
| `--muted` | `#797770` | `#CDBFC2` | النصوص الثانوية |
| `--primary` | `#2C151A` | `#2C151A` | خلفية عنابية داكنة |
| `--on-primary` | `#FEFEFD` | `#FFF8F9` | النص فوق الخلفية العنابية |
| `--green` | `#40634A` | `#A5C7AC` | النصوص والأيقونات الخضراء |
| `--rose` | `#9E727B` | `#D3A6B2` | التفاصيل الوردية |
| `--surface` | `#FEFEFD` | `#211A1C` | البطاقات |
| `--surface-soft` | `#FCFBF8` | `#2A2023` | الأسطح الثانوية |
| `--background` | `#FEFEFD` | `#191416` | خلفية الصفحة |
| `--line` | `#F6F3ED` | `#3B3033` | الحدود الخفيفة |
| `--radius` | `16px` | `16px` | زوايا البطاقات |

الرموز موجودة في بداية `src/styles/global.css`؛ تعديلها يغيّر الهوية المشتركة.

## الخطوط

- النص العربي: Tajawal.
- العناوين العربية: Noto Naskh Arabic.
- الإنجليزية: Tajawal مع Arial كبديل.
- لم يتم تحديد الخط الأصلي من الصورة؛ هذه اختيارات قريبة من روحها وتناسب القراءة العربية.
- `--font-body` و`--font-heading` هما المرجع للصفحات الجديدة.

## قواعد البناء

- عرض المحتوى الأقصى 1180px عبر `.container`.
- المساحات الخارجية 32px على الكمبيوتر و16px على الموبايل لكل جانب.
- `.section` للأقسام، `.section-heading` للعناوين، `.tinted` للخلفيات الثانوية.
- `.button` للزر الأساسي، `.button-outline` للثانوي.
- الشبكات: أربع بطاقات مميزات على الكمبيوتر، اثنتان على الشاشات الصغيرة؛ الدورات ثلاث ثم اثنتان ثم واحدة.
- استخدمي خصائص منطقية مثل `margin-inline` و`padding-inline` و`text-align:start`.
- استخدمي `usePreferences()` للحصول على `copy` و`language` و`theme` في أي صفحة.
- لا تكرري ألوانًا ثابتة في صفحات المستقبل؛ استخدمي الرموز المشتركة.
- حافظي على الأزرار الحقيقية، وضوح التركيز بالكيبورد، والنص البديل للصور.

مثال مكوّن صفحة جديدة:

```jsx
import { usePreferences } from '../context/PreferencesContext';

export default function NewPage() {
  const { copy } = usePreferences();
  return <section className="section container">
    <div className="section-heading"><h1>{copy.newPageTitle}</h1></div>
  </section>;
}
```

أضيفي `newPageTitle` داخل `ar` و`en` أولًا.

## تنسيق صفحات الليرنر والإنستركتر

### الملفات المشتركة
- role-navigation.css: الناف بار المشترك، وفوتر الإنستركتر،
  ورسائل النتائج الفارغة، وبطاقة حذف المهمة.
- points-badge.css: تصميم رصيد النقاط عبر مكوّن PointsBadge.
- توحيد شكل رصيد النقاط لا يعني توحيد قيمة الرصيد؛
  كل دور يأخذ القيمة من مصدر بياناته الحالي.

### ملفات الإنستركتر
- instructor-dashboard.css: لوحة التحكم.
- instructor-courses.css: قائمة الدورات.
- instructor-create-course.css: صفحة إنشاء الدورة الحالية.
- instructor-details.css: المنهج، وتعديل الدرس، والمهمة،
  ومعاينة الدورة، والأداء، والتقييمات.

احتفظي بملف instructor.css؛ الملفات الجديدة تعدّل التنسيق
فوق القواعد الموجودة، ولا تستبدل وظائف الصفحات.

### قواعد التصميم
- خط النصوص: var(--font-body)، وهو Tajawal.
- خط العناوين: var(--font-heading)، وهو Noto Naskh Arabic.
- النص الرئيسي: 16px.
- النص المساعد: 13–14px.
- ارتفاع حقول النماذج المعدّلة: 48px.
- ارتفاع الأزرار: 44px على الأقل.
- عرض المحتوى الأقصى: 1180px.
- استخدمي margin-inline وpadding-inline لدعم العربية والإنجليزية.
- استخدمي --text للنص الرئيسي و--muted للنص المساعد.
- لا تستخدمي --primary كنص فوق سطح داكن.
- لا تغيّري مصدر بيانات الصفحة عند تعديل شكلها.

### الكلاسات المطلوبة
- role-header في ناف بار الليرنر والإنستركتر.
- instructor-detail-page في الجذر الخارجي لصفحات التفاصيل الست.
